# Capstone Research Milestone

## Overview

This project was created as part of a capstone research milestone to explore technologies that may be used in the development of a service management platform. The sample application demonstrates a basic web-based system where users can log in and manage service requests.

## Technologies

- Next.js
- React
- JavaScript
- Tailwind CSS
- npm
- Git/GitHub

## Purpose

The purpose of this project was to gain hands-on experience with the selected development tools and learn how they can be used to create an interactive web application. The project includes user input, application logic, navigation between pages, and displaying submitted information.

## Running the Project

Requirements

Node.js and npm

Java JDK 24

Git

1. Run the Backend (Spring Boot)

Open a terminal in the project folder and run:

cd backend
.\mvnw.cmd spring-boot:run

The backend runs at http://localhost:8080.

2. Run the Frontend (Next.js)

Open a second terminal in the project folder and run:

cd service-request-app
npm install
npm run dev

The frontend runs at http://localhost:3000.

3. Open the Application

Visit http://localhost:3000 in your browser.

Both the frontend and backend must be running for the application to work correctly.
