# Capstone Research Milestone

## Overview

This project was created as part of a capstone research milestone to explore technologies that may be used in the development of a service management platform. The sample application demonstrates a basic web-based system where users can log in and manage service requests.

## Technologies

- Next.js
- React
- JavaScript
- Tailwind CSS
- npm
- Git/GitHub

## Purpose

The purpose of this project was to gain hands-on experience with the selected development tools and learn how they can be used to create an interactive web application. The project includes user input, application logic, navigation between pages, and displaying submitted information.
